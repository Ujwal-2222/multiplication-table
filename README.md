# Question: Print Multiplication Table

# Write a program that takes a number as input from the user and prints the multiplication table of that number up to 10.

# Instructions:
Take an integer input from the user.
Print the multiplication table for the entered number, from 1 to 10.
Don't change or modify the filename
Don't create a new file for the program just do the code in the existing or given file.
# Output instructions
- Print the table (Line by line)
- After printing 5 x 1 = 5 print the 5 x 2 = 10
- Here it is an **letter small ' x '**
